# MENÚ DIGITAL – RESTAURANTE GOURMET

## 1. Descripción del proyecto
El presente proyecto consiste en el desarrollo de una aplicación de escritorio
para un restaurante, cuyo objetivo es mostrar un menú digital organizado
por categorías.

La aplicación permite:
- Visualizar las categorías de productos
- Mostrar los platillos según la categoría seleccionada
- Consultar los precios de cada producto

El sistema fue desarrollado en Python utilizando la librería Kivy para la
interfaz gráfica.

---

## 2. Tecnologías utilizadas
- Python 3.9
- Kivy
- JSON para almacenamiento de datos
